# Salary Prediction using Simple Linear Regression

## 💼 Overview
This project builds a Simple Linear Regression model to predict employee salaries based on years of experience. It demonstrates the basics of regression modeling and data visualization.

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## 📊 Model Summary
- Trained a linear model on salary dataset
- Visualized regression line and data distribution
- Predicted salary values based on input experience

## 📁 Files
- `linear_regression_with_salary_dataset.ipynb`: Main notebook with model training and visualization
- `README.md`: Project summary and instructions

## 🚀 How to Run
1. Clone the repo
2. Install dependencies: `pip install pandas matplotlib scikit-learn`
3. Open the notebook in Jupyter
4. Run cells sequentially to view predictions

## 📌 Use Case
Useful for HR analytics, salary forecasting, and educational demos on regression modeling.
